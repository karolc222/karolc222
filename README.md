## 🌸 About Me

I'm a Software Engineer with a background spanning software engineering, digital media, and product support. I'm interested in the relationship between technology and the people who use it — particularly how complex systems can become useful, understandable and human.

I recently completed an MSc in Software Engineering, followed by an intensive C# / .NET training programme, where I built backend services and data-driven applications as part of a team. This gave me a strong grounding in layered architecture, REST APIs, testing and data modelling, alongside my existing work in mobile and web development.

I'm particularly interested in backend engineering, clean architecture, and the kinds of software that sit behind things people rely on every day — whether that's fintech systems, legal technology, AI-powered tools or digital publishing platforms.

I enjoy learning new domains and technologies, understanding how things work beneath the interface, and getting absorbed in difficult problems.

Whether I'm working with APIs, native mobile applications or frontend interfaces, I'm interested not only in how a system works, but in what it enables people to do.

## 🚀 Main Projects

### 🚪 FirstDoor

**C# • .NET • ASP.NET Core • REST APIs • SQL**

Backend for a job-search platform, built collaboratively as my final project during an intensive C# / .NET training programme.

The project involved designing APIs, modelling data, implementing business logic and working collaboratively as part of a team of five.

[View the project →](https://github.com/karolc222/firstDoorBackEnd)


### ⚖️ LegalBestie

**Swift • SwiftUI • MVVM • OpenAI API**

A native iOS application designed to make legal information more approachable.

LegalBestie combines conversational AI with structured decision-making, allowing users to explore legal scenarios and receive information in a more accessible format.

[View the project →](https://github.com/karolc222/LegalBestie)


### 💼 RetireRight

**Swift • SwiftUI • MVVM**

A financial planning application designed to help users explore retirement scenarios and understand how different financial decisions may affect their future.
